# Smart Plotters

This repository contains code for quickly plotting and creating images using astronomical data. The majority of the python files are dealing with different use cases for querying catalogs and plotting their contents quickly and easily. In addition, there is code for combining different sets of astronomical images to make three-color images or plot contours. 

## Tutorials
- Using [Cutout](https://github.com/SpacialTree/smart-plotters/blob/main/tutorials/tutorial_cutouts.ipynb) to use Cutout2D to efficiently make cutouts of images and create three-color images.
- [Cross-matching catalogs](https://github.com/SpacialTree/smart-plotters/blob/main/tutorials/tutorial_catalog_matching.ipynb)
